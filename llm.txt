# @proxies-sx/mcp-server - AI Agent Context

> MCP server for Proxies.sx: residential and mobile proxies metered per GB. An agent reads live stock, gets its credentials, builds Pool Gateway proxy URLs, manages dedicated ports, Private Pools and Reserved IPs, reads usage and pricing, and opens support tickets.

## Quick Start

```bash
claude mcp add proxies-sx -e PROXIES_API_KEY=psx_your_api_key_here -- npx -y @proxies-sx/mcp-server
```

Any other MCP client (Claude Desktop, Cursor, Windsurf, Cline):

```json
{
  "mcpServers": {
    "proxies-sx": {
      "command": "npx",
      "args": ["-y", "@proxies-sx/mcp-server"],
      "env": {
        "PROXIES_API_KEY": "psx_your_api_key_here"
      }
    }
  }
}
```

Create the API key at https://client.proxies.sx/account and add GB at https://client.proxies.sx/purchase.

## Modes

- **API key (standard):** `PROXIES_API_KEY`. An account with GB on it. Customer key scopes: ports:read, ports:write, ports:rotate, billing:read, account:read, account:write, traffic:read, tickets:read, tickets:write. `billing:write` (buying through the API) exists only for reseller and admin keys.
- **x402 wallet (optional):** `AGENT_WALLET_KEY`, the 0x private key of a USDC wallet on Base. No account: the agent pays per GB on-chain.
- **Both:** set both variables.

`PROXIES_API_URL` is optional. Default `https://api.proxies.sx`; a trailing `/v1` is accepted.

## Pool Gateway (the main product)

One endpoint: `gw.proxies.sx`, HTTP port 7000, SOCKS5 port 7001. The username carries the routing:

```
psx_<account>-<pool>-<country>[-iptype-<class>][-carrier-<name>][-city-<name>][-state-<code>][-asn-<number>][-sid-<id>][-rot-<mode>][-failover-<policy>][-ttl-<seconds>]
```

Rules:
- pool `peer`: the main network, residential and mobile, most countries. pool `mbl`: carrier modems in exactly US, GB, FR, NL, PL, GE. GE is Georgia, not Germany: `mbl-de` never works, use `peer-de`. `any` / `best`: the gateway chooses.
- iptype: `mobile`, `residential`, `isp`. The ISP (static) class is served only when named.
- rot: `sticky` and `hard` hold one device; `auto5`, `auto10`, `auto20`, `auto60` move to another device on that interval (auto10 is the default); `ondemand` picks again per connection.
- `sticky`, `hard` and `auto*` persist across connections only with `-sid-<id>` (lowercase letters, digits, `_`). `-session-` is ignored without an error.
- Sticky holds the device, not the IP: a mobile carrier can change the exit IP.
- Limits per account: 500 concurrent connections, 250 sessions.
- Password: the proxy password from `pool_get_my_credentials`, or a `pak_` key. Not the account login password.
- Price: per GB, lower per GB on larger purchases, time is free. Read it live with `get_pricing`.

Typical flow:

```
pool_get_stock {country: "de"}
pool_get_my_credentials
pool_build_proxy_url {proxyUsername, password, pool: "peer", country: "de", ipType: "residential", rotation: "sticky", sid: "job1"}
-> http://psx_abc123-peer-de-iptype-residential-sid-job1-rot-sticky:PASSWORD@gw.proxies.sx:7000
```

Gateway error codes (pass the text to `pool_explain_error`): E_AUTH_REQUIRED, E_AUTH_INVALID (wrong proxy password), E_BALANCE_EXHAUSTED (no traffic left, the password is fine), E_CAP_EXCEEDED, E_RATE_LIMITED_AUTH, E_RATE_LIMITED_CONN, E_SESSION_LIMIT, E_NO_STOCK_COUNTRY, E_STOCK_DEGRADED, E_SSRF_BLOCKED, E_WRONG_PORT, E_INTERNAL.

## Tool errors

A failing tool returns `isError: true`. For a missing or revoked key (401), a missing scope (403), a rate limit (429) and server errors (5xx) the text ends with a `What to do:` line. Keys and passwords are masked in error text.

## Example conversations

### A proxy in a country without modems
```
User: I need a residential proxy in Germany that keeps the same device.
Agent: [pool_get_stock, pool_get_my_credentials, pool_build_proxy_url]

http://psx_abc123-peer-de-iptype-residential-sid-job1-rot-sticky:PASSWORD@gw.proxies.sx:7000
```

### A dedicated port on a carrier modem
```
User: Create a dedicated mobile port in Poland.
Agent: [list_available_countries, create_port]

Port created:
HTTP: http://user:pass@<server>:<port>
```

### Move a dedicated port to another modem
```
User: Rotate my main port.
Agent: [list_ports, rotate_port]

The port is on another device now and its port numbers have changed. The API does not return the exit IP (x.x): send a request through the proxy to see it.
```

### Pay with a wallet (x402)
```
User: Buy 1 GB of pool access with my agent wallet.
Agent: [x402_pool_pricing, x402_wallet_balance, x402_get_pool_access]

One credential for gw.proxies.sx:7000, valid for every country of the tier.
```

## x402 payment flow (optional path)

```
1. GET /v1/x402/pool or /v1/x402/proxy        -> 402 with the payment options
2. the server pays USDC on Base from the agent wallet
3. the same request again with header Payment-Signature: <transaction hash>
4. the API verifies the payment and returns credentials and a session token
```
